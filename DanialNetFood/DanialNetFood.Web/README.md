# سامانه یکپارچه سفارش غذا DanialNetFood

سامانه DanialNetFood یک پلتفرم جامع، مقیاس‌پذیر و بومی برای مدیریت چرخه کامل سفارش آنلاین غذا است. این پروژه با رویکرد Enterprise طراحی شده و چالش‌های واقعی مانند همزمانی (Concurrency)، پایداری داده‌ها و توزیع جغرافیایی را به طور کامل حل کرده است.

## قابلیت‌های شاخص لایه Enterprise

### ۱. مدیریت همزمانی و موجودی (Concurrency Control)
- **پایداری موجودی:** استفاده از مکانیزم Optimistic Concurrency با RowVersion برای جلوگیری از فروش بیش از حد (Overbooking) در ساعات اوج بار. سیستم به صورت خودکار تداخل‌های همزمان در خرید آخرین پرس غذا را مدیریت می‌کند.

### ۲. توزیع جغرافیایی و Geofencing
- **محدوده سرویس‌دهی:** رستوران‌ها دارای مختصات جغرافیایی و شعاع سرویس‌دهی (Service Radius) هستند. سیستم با استفاده از فرمول Haversine، فاصله کاربر تا رستوران را محاسبه کرده و در صورت خارج بودن از محدوده، از ثبت سفارش جلوگیری می‌کند.

### ۳. موتور کیف پول و تسویه حساب آنی (Fintech Engine)
- **تراکنش‌های اتمیک:** تمامی پرداخت‌ها از طریق کیف پول داخلی انجام می‌شود.
- **Auto-Refund:** در صورت لغو سفارش، مبلغ به صورت آنی و خودکار در یک تراکنش واحد به کیف پول مشتری بازمی‌گردد.
- **تسهیم سود:** پس از تحویل موفق، سهم رستوران و کارمزد پیک به صورت خودکار محاسبه و واریز می‌شود.

### ۴. معماری حافظه کش دوگانه (Hybrid Caching)
- **پاسخگویی سریع:** لیست رستوران‌ها و منوها در لایه حافظه موقت (IMemoryCache) نگهداری می‌شوند.
- **Cache Invalidation:** به محض تغییر در منو یا قیمت‌ها توسط رستوران‌دار، کش مربوطه به صورت خودکار ابطال و به‌روزرسانی می‌شود تا داده‌های فاسد (Stale Data) به کاربر نمایش داده نشود.

## معماری و پشته فنی
- **بک‌آند:** ASP.NET Core 10 MVC
- **دیتابیس:** PostgreSQL (بهینه‌سازی شده برای محیط داکر)
- **ارتباطات آنی:** SignalR Core
- **امنیت:** Cookie Authentication با هشینگ BCrypt
- **تست خودکار:** Playwright برای تایید سناریوهای سفارش‌گذاری

## راهنمای اجرا با داکر (Docker Compose)

برای اجرای کامل سیستم شامل اپلیکیشن و دیتابیس PostgreSQL، دستور زیر را در پوشه ریشه اجرا کنید:

```bash
docker compose up --build
```

پس از اجرا، سیستم به صورت خودکار عملیات EF Migrations را انجام داده و با داده‌های اولیه (شامل ۲۰ رستوران، منوهای کامل، کاربران و پیک‌های آنلاین) آماده به کار خواهد بود.
