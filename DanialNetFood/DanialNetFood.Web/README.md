# سامانه یکپارچه سفارش غذا DanialNetFood

دانیال نت فود یک پلتفرم جامع سفارش آنلاین غذا است که بر پایه معماری ASP.NET Core MVC توسعه یافته است. این پروژه بر مدیریت سمت سرور، الگوهای طراحی سازمانی و تجربه کاربری پویا تمرکز دارد.

## ویژگی‌های کلیدی
- مدیریت سبد خرید با استفاده از Session و بروزرسانی AJAX (بدون رفرش صفحه).
- سیستم تخفیف هوشمند با استفاده از الگوی طراحی Strategy.
- ردیابی زنده وضعیت سفارش با استفاده از SignalR.
- معماری لایه‌بندی شده با الگوهای Repository و Unit of Work.
- لایوت‌های مجزا برای بخش عمومی و پنل مدیریت رستوران.
- استفاده از Tailwind CSS به صورت محلی و بومی.

## پشته فنی
- بک‌آند: .NET 10 (ASP.NET Core MVC)
- دیتابیس: SQLite (قابل ارتقا به SQL Server/PostgreSQL)
- فرانت‌آند: Tailwind CSS, jQuery, SignalR JS Client

## راهنمای راه‌اندازی

### پیش‌نیازها
- نصب .NET SDK نسخه 10

### مراحل اجرا
1. مخزن را کلون کنید.
2. به پوشه `DanialNetFood.Web` بروید.
3. دستور `dotnet run` را اجرا کنید.
4. دیتابیس به صورت خودکار ایجاد و با داده‌های اولیه (رستوران‌ها، منوها و کاربران) پر می‌شود.

### اطلاعات ورود پیش‌فرض
- ادمین (رستوران‌دار): نام کاربری `admin` رمز عبور `admin123`
- مشتری: نام کاربری `user` رمز عبور `user123`

## ساختار پوشه‌بندی
- `Controllers`: منطق کنترل درخواست‌ها
- `Models`: مدل‌های داده و ViewModels
- `Data`: مدیریت دیتابیس، مخازن (Repositories) و واحد کار (Unit of Work)
- `Services`: استراتژی‌های محاسبه تخفیف
- `Hubs`: هاب SignalR برای ارتباطات بلادرنگ
- `Views`: صفحات Razor و لایوت‌ها
- `wwwroot`: فایل‌های استاتیک شامل Tailwind و اسکریپت‌های جاوااسکریپت
