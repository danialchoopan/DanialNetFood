# مستندات داخلی و رویدادهای SignalR

این سند به تشریح ساختار داخلی اکشن‌ها و مکانیزم تعاملات آنی در سامانه DanialNetFood می‌پردازد.

## ساختار کنترلرها و روت‌های اصلی

### CartController (مدیریت سبد خرید با Session)
- **POST /Cart/AddToCart:** دریافت شناسه غذا و افزودنی‌ها، به‌روزرسانی JSON سبد خرید در Session و بازگرداندن Partial View سبد.
- **POST /Cart/RemoveFromCart:** حذف آیتم خاص بر اساس هشِ افزودنی‌ها جهت دقت در حذف.

### OrderController (فرآیند ثبت سفارش)
- **GET /Order/Checkout:** نمایش فاکتور نهایی و فرم اعمال کد تخفیف.
- **POST /Order/ApplyDiscount:** اعتبارسنجی کد تخفیف با استفاده از Strategy Pattern.
- **POST /Order/PlaceOrder:** عملیات تراکنشی شامل کسر موجودی، کسر از کیف پول و ثبت نهایی (تحت مدیریت Unit of Work).

## مستندات SignalR Hub (OrderHub)

سامانه از `OrderHub` برای همگام‌سازی وضعیت سفارشات بین سه ضلع مشتری، رستوران و پیک استفاده می‌کند.

### متدها (Server Methods)
- **JoinOrderGroup(orderId):** کلاینت‌ها (مشتری و رستوران) برای دریافت آپدیت‌های یک سفارش خاص عضو یک گروه می‌شوند.
- **UpdateOrderStatus(orderId, status):** توسط ادمین رستوران یا پیک فراخوانی می‌شود تا وضعیت جدید را به اطلاع سایرین برساند.

### رویدادها (Client Events)
- **ReceiveStatusUpdate:** زمانی که وضعیت سفارش تغییر می‌کند، این رویداد در سمت کلاینت اجرا شده و المان‌های بصری را بدون رفرش به‌روز می‌کند.
- **NewOrderAlert:** اطلاع‌رسانی آنی به پنل مدیریت رستوران به محض ثبت سفارش جدید توسط مشتری (همراه با اعلان صوتی بومی).

## ساختار داده در Session
سبد خرید به صورت یک شیء سریالایز شده با ساختار زیر در `HttpContext.Session` ذخیره می‌شود:
```json
{
  "Items": [
    {
      "FoodId": 1,
      "FoodName": "چلو کباب",
      "Quantity": 1,
      "Options": [{"Id": 1, "Name": "نوشابه", "Price": 25000}]
    }
  ],
  "TotalAmount": 375000
}
```
